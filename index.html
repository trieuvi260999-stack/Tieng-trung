⚙️ Cài đặt Trợ lý Bản xứ

Khóa API được lưu trực tiếp trên iPhone của bạn, giúp kết nối thẳng tới Google Gemini với tốc độ nhanh nhất.

Chưa có mã? Mở aistudio.google.com/apikey → Đăng nhập Gmail → Bấm Create API key → Sao chép và dán vào ô trên.
💡 Mẹo giọng hay như người thật trên iPhone: Vào Cài đặt iPhone → Trợ năng → Nội dung được đọc → Giọng nói → Tiếng Trung (Trung Quốc) và tải bản Tingting (Nâng cao) hoặc Lili (Nâng cao). App sẽ tự động nhận giọng này!
